# Environment Configuration Guide

## Quick Setup

1. Copy example file:
```bash
cp .env.example .env
```

2. Generate JWT secrets:
```bash
openssl rand -base64 32
```

3. Set required variables in `.env`

## Required Variables (Minimum)

```env
MONGODB_URI=mongodb://localhost:27017/game_engine_ai
JWT_SECRET=your-generated-secret-32-chars-min
JWT_REFRESH_SECRET=another-generated-secret-32-chars-min
```

## AI Integration (Optional but Recommended)

### OpenAI (GPT-4 for text, DALL-E for images)
```env
OPENAI_API_KEY=sk-proj-...
```
Get key: https://platform.openai.com/api-keys

### Replicate (Stable Diffusion, Image models)
```env
REPLICATE_API_TOKEN=r8_...
```
Get key: https://replicate.com/account/api-tokens

### ElevenLabs (Voice generation + real SFX sound effects)
```env
ELEVENLABS_API_KEY=...
```
Get key: https://elevenlabs.io/app/settings/api-keys
Used for: /ai/generate-voice and /ai/generate-sfx (real .mp3 audio)

### Meshy.ai (Real text-to-3D model generation – .glb / .fbx / .obj / .usdz)
```env
MESHY_API_KEY=...
```
Get key: https://www.meshy.ai/api (Sign up → API → Generate key)
Used for: /ai/generate-3d-model (returns real downloadable .glb URLs)
Without this key: falls back to Replicate SDXL isometric image preview

### Meta MusicGen via Replicate (Real game music audio)
Already covered by REPLICATE_API_TOKEN above.
Used for: /ai/generate-music (returns real .mp3 audio URL via meta/musicgen model)

## Mock Mode

If you don't have AI API keys, set:
```env
MOCK_AI_MODE=true
```

This will return sample data for all AI endpoints.

## Testing Configuration

For development/testing without AI costs:
```env
NODE_ENV=development
MOCK_AI_MODE=true
ENABLE_AI_GENERATION=true
```

## Production Configuration

For production with real AI:
```env
NODE_ENV=production
MOCK_AI_MODE=false
ENABLE_AI_GENERATION=true
OPENAI_API_KEY=sk-...
REPLICATE_API_TOKEN=r8_...
```
